### Projects

**[Metis](https://github.com/linyeping/Metis)** — Desktop AI agent built with Electron + Python.  
Implements a full agent loop with skill dispatch, checkpoint/rollback, and MCP tool connectors.  
Each task runs in an isolated Git worktree sandbox. Android companion uses the accessibility API for on-device automation.

**[GemMate](https://github.com/linyeping/GemMate)** — On-device study companion (Flutter).  
Runs Gemma 4 locally via LiteRT, falls back to LAN Ollama. Includes a smart router, SM-2 spaced repetition, OCR/STT input, and six-language support.
